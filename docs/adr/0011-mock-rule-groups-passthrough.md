# 0011 - HTTP Mock 规则组与透传模式

日期:2026-09-11 · 状态:accepted

计划 13(ADR-0009)跑通后,规则平铺的两个痛点暴露:同一路由的条件变体每条重复存 method/path_template
(改路由要逐条改,漂移面大);命中记录只有"命中/未命中"二元,演练"真实依赖在身边"的场景(上游慢/5xx)
没有出口。本 ADR 以四决策引入**规则组实体化**与**透传模式**:

1. **规则组实体化**:method + path_template 上移到新表 `mock_rule_groups`(同实例内 method+path 唯一,
   重路 400),`mock_rules` 挂 `group_id` 只存条件+响应——组 = 同一(方法,路径)下条件变体的容器,
   规则不再重复存路由;删组连组下规则软删(历史命中 rule_id 仍可追溯)。
2. **匹配语义两级化**:由实例内全局扁平 `sort_order` 改为「组序→组内序」两级遍历(组或规则停用即跳过,
   首条命中语义不变)。**ADR-0009 的匹配顺序与未命中语义被本 ADR 部分取代**;存量迁移保序:
   组序 = 该组旧全局序的最小 `sort_order`(MIN)——「存量行为等价」有前提:同路由变体在旧全局序中
   连续、且各组模板不重叠同一路径(如旧序 A1(/a/{id})、B(/a/special)、A2(/a/{id}) 交错时,
   迁移后组内序判定可能翻转),现网存量已核实满足此前提。
3. **透传模式**:实例级显式开关 `passthrough_enabled` + 上游 `upstream_base_url`(须 http(s):// 开头,
   开透传必须给地址)。未命中请求原样转发上游(剥 hop-by-hop 头,host/content-length 重算);
   **上游任何 HTTP 响应(含 4xx/5xx)都算透传成功、原样带回**——"真实依赖的 5xx 是被测系统要演练的
   现场",mock 不替上游抹平;仅传输层失败(连接 5s / 读 30s 超时、DNS、非法 URL)回落实例默认响应,
   命中记录 `error=forward-failed`。关开关即回纯 mock 语义(未命中直接兜底)。
4. **命中记录升维**:`mock_hits` 新增 `outcome` 三态(`matched` 命中 / `fallback` 兜底 / `forwarded` 透传)
   与 `response_body` 落库(64KB 截断,与请求体同口径),兜底/透传的实收响应可回看;组视角下未命中行按
   「method 相同 + 实际路径能被组模板匹配」归因到组(打过这个路由但没接住)。

## Considered Options

- 规则继续平铺、另加"路由签名"冗余列做分组展示——拒:双写漂移,改路由仍要逐条改,实体化一步到位。
- 组只当标签、匹配仍走单层扁平 sort_order——拒:同路由变体的插入/移动语义说不清;两级序与前端组卡片
  一一对应,库序=界面序,心智一致。
- 未命中只兜底不透传(计划 13 原语义)——拒:mock 永远说谎,演练不了上游故障(超时/5xx)下被测系统的
  真实表现;透传是 mock 域从"挡板"走向"仿真"的分水岭。
- 透传把上游 5xx 换写成 502 或兜底——拒:被测系统要练的就是收到上游真实状态码;传输层失败(上游根本
  没说话)才回兜底,error 落库可区分"上游回了坏东西"与"上游够不着"。
- outcome 靠 matched 布尔 + error 字符串推断——拒:三态是稳定领域概念,列表四态过滤(filter=forwarded)
  与按组归因都依赖它,推断规则会随语义漂移。

## Consequences

- 存量迁移一条 SQL(`scripts/mysql-alter-plan15.sql`):规则按 method+path 归组、组序=旧全局序
  MIN(sort_order),迁移后行为等价(前提见决策 2:同路由变体旧序连续/各组模板不重叠同一路径);
  开发库已执行并核对(3 组存量均满足前提、分组正确)。
- 规则载荷瘦身:建/改规则不再带 method/path_template;规则改挂组暂不支持(`update_rule` 忽略
  group_id),需要挪组 = 删了重建。
- 透传给实例端口新增**出站调用面**:上游地址成为实例配置的一部分,误配/改错端口是运维动作(冒烟清单
  含"上游端口改错→兜底"用例);响应侧 content-encoding 必须剔除(httpx 已透明解压,原样带回会
  ERR_CONTENT_DECODING_FAILED)、set-cookie 多值保真。
- 命中表行变宽(response_body 64KB 上限),每实例滚动 1000 条口径不变;命中列表新增四态过滤与按组
  预过滤,组「命中记录详情」按组预过滤跳转。

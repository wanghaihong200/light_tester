# 0013 - UI 执行计划用例源:切换为 web 仓扫描注册表(Web用例)

日期:2026-09-17 · 状态:accepted

ADR-0012 决策 4 定执行计划骨架时,api 域用例源走「注册表扫描」(Java TestNG 方法级,仓×分支×类×方法),
ui 域走「平台脚本库 UiScript × 分支物料过滤」(文件级,`test_{script_id}_{拼音}.py` 存在性判定)。
两轨并行暴露出 ui 域的硬伤:手写 pytest 用例(如 light_web_ui_autotest_demo 形态)无法进执行计划,
平台侧编辑脚本库才可见,与「仓是唯一事实源」原则相悖。本 ADR(grilling 会话 2026-09-17 定案,
Q1-Q13 全记录在案)把 ui 域对齐 api 域骨架——**搬骨架,不搬解析器**(api 域解析的是 Java 正则,
web 域是 pytest,解析必须全新写):

1. **用例源完全替换,拒双源并存**:ui 计划勾选用例改为 web 仓扫描注册表,UiScript 脚本库不再进
   执行计划;新链路 = 录制→导出→推送(不变)+ 扫描→勾选。录制/执行/导出域本身不动。
2. **Web用例实体,函数级扫描**:定位键「仓×分支×文件×函数」,与 api 的「类×方法」同构(api 侧
   容器=类,web 侧容器=文件;demo 工程纯函数式无 Test 类,类槽位不可复用)。标题=docstring 首行、
   缺省回落函数名;`account` 等仓侧 marker 只读展示为标签(仓是事实源,平台不改标记);浏览器后缀
   `[chromium]` 剥离,一函数一用例,浏览器是执行时维度不是用例数量。
3. **ast.walk 解析全仓 `test_*.py`**:递归扫全仓(跳过 `.venv`/缓存/隐藏目录),不读 pyproject
   testpaths(存量导出物在仓根、demo 形态在 tests/,一网打尽);导出生成物与手写用例一视同仁,
   不按命名约定反查来源(手写用例会打破约定,做一半比不做乱)。拒正则(pytest 装饰器多行/叠加/
   文件级 pytestmark,正则脆;项目已有 ast 处理 pytest 源码先例)。
4. **交互与 api 侧逐字对齐**:PlanDialog ui 分支加「扫描 {分支}」按钮,仅手动触发(分支未选/未扫
   时用例区禁用+引导文案),复用 api 侧三段式编排 sync_repo(切分支)→scan→registry 增量合并;
   stale 语义同接口(重扫消失即 stale、重现复活、不扫不动,各分支独立)。
5. **selection 改 nodeid,执行精确到函数**:勾选提交 `{file_path, function}`,执行时
   `pytest nodeid...`;`${SELECTION}` 空格分隔传法预期零改动(nodeid 是 pytest 原生寻址),实施时
   验证。`_enrich_selection`/`_resolve_selection` 的 ui 分支同步改造;报告链不动(junit_parse 已
   通吃两域,CaseTree 的类→方法分组对 pytest 输出天然契合)。
6. **范围边界**:只做 web 仓(app 仓用例形态差异大,且已有设备用例同步机制,不入域);只服务执行
   计划,不做独立用例库列表页、不做功能用例树覆盖率关联;存量 ui 计划打开编辑时旧勾选(脚本库
   引用)作废、要求重扫重选,不做数据迁移(平台未生产化)。

## Considered Options

- 双源并存(脚本库 + 扫描注册表)——拒:执行计划页出现两套勾选交互;脚本库源即 ADR-0012 ui 半边,
  保留即保留手写用例进不了计划的原伤。
- 文件级粒度(沿用现导出约定)——拒:api 域方法级,ui 文件级即"勾 1 个跑全文件",报告对不上选择;
  函数级是本次对齐的核心诉求。
- 保留浏览器维度(一函数×N浏览器展开多行)——拒:demo 工程只跑 chromium,展开是伪维度;将来按
  浏览器执行属执行选项,不是用例数量。
- 解析 pyproject testpaths 按配置扫——拒:v1 收益抵不过解析构建配置的复杂度;真出现"不想被扫的
  测试文件"再加排除规则。
- 区分"平台导出/手写"来源标签——拒:依赖 `test_{script_id}_{拼音}` 命名约定反查,手写用例打破
  约定即失效;「仓是唯一事实源」下平台无需知道用例怎么来的。

## Consequences

- 取代 ADR-0012 决策 4 中 ui 域的用例源半边(「分支即事实源:仅列当前分支已导出的」物料过滤路线
  退役);`/ui-script-materials` 端点与 PlanDialog ui 物料表格随之废弃。
- UiScript 脚本库继续存在(录制/平台内执行/导出域),但它与执行计划之间不再有直接引用关系;
  导出推送仍是把录制资产送进仓的通道。
- 注册表模型需容纳两类键语义(api=类容器 / web=文件容器),共用一套表+类型维度或同构双表由实施
  定,倾向复用同一套避免双倍维护;唯一约束相应扩展。
- 存量 ui 计划的 selection 快照语义变更:历史执行记录不迁移(快照只增不删原则不破),仅编辑时作废
  重选。
- light_api_autotest_demo 本地目录为 Java+TestNG 工程属正常态(api 域扫描器本就解析 Java);
  pytest+playwright 是 web 域约定,勿跨域套用。
